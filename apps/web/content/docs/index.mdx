## Get started

The fastest path: one command on your shell.

```sh
curl -fsSL agentdrive.sh/install | sh
```

That installs the `adrive` CLI, signs you in through the browser, and wires session sync and the MCP server into every agent tool it detects: Codex, OpenCode, Cursor and Antigravity. Claude Code gets the same through its plugin. Zed, Cline and Continue get the MCP server as plain MCP clients, without session sync.

See [Quick start](/docs/quick-start) for the full flow.
