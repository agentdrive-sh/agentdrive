I use Claude Code, Codex, OpenCode, Cursor and Antigravity. Most days I use at least three of them. Each one is good at something the others aren't, and every time I switch I end up doing the same chore: copying the plan out of one session, pasting it into the next, explaining what was already tried, and pointing at the files that changed.

So I was the copy-paste bus between my agents. AgentDrive is what I built so I could stop doing that.

## What it does

AgentDrive is a shared workspace that lets Claude Code, Codex, OpenCode, Cursor and Antigravity pick up each other's sessions, with provenance on every artifact and portable storage.

In practice:

1. **Sync runs in the background.** A hook in each agent CLI hands the session to the `adrive` CLI, which uploads a redacted transcript, plus any files the agent wrote that git doesn't track, to your workspace. You don't change how you work.
2. **Any agent can resume.** Open a different agent in the same project and ask it to continue. It calls `drive_sessions` to see recent sessions from every harness and `drive_resume` to load a compact handoff brief: the goal, the files touched and the most recent turns. In Claude Code that's `/agentdrive:resume`. From a shell it's `adrive resume`.
3. **Every artifact has provenance.** Each upload and each session run keeps which agent CLI produced it, so the workspace timeline shows which agent did what, and when.

Session sync is the part you notice first. Underneath it is the same workspace any MCP client can use: 22 MCP tools (18 stable, 4 experimental sandbox tools) for versioned files, semantic search, run logs and share links.

## Install

One line on macOS or Linux:

```bash
curl -fsSL agentdrive.sh/install | sh
```

It installs the `adrive` CLI, signs you in through the browser, and wires session sync, the MCP server and the resume and sessions commands into each agent it finds. In Claude Code, AgentDrive is a plugin:

```
/plugin marketplace add agentdrive-sh/agentdrive-mcp
/plugin install agentdrive@agentdrive
```

Setup also approves the AgentDrive hooks in Codex for you; on an older Codex, approve them once via `/hooks`.

Cline, Zed and Continue get the workspace tools as plain MCP clients. They don't have session sync.

## Privacy

Syncing transcripts means uploading what you and your agents said, so you control all of it with `adrive privacy`:

- **Auto-context:** at session start, list recent sessions from your other agents in this project.
- **Artifact sync:** upload files your agents wrote that git doesn't track, and allow `adrive watch`, which is meant to upload a whole folder. In CLI 1.4.0 watch uploads nothing, because of a bug fixed in the next release, so use hook sync or `adrive push` meanwhile.
- **Transcript sync:** upload session transcripts.
- **Private Workspace:** encrypt transcripts and files on your machine before upload. Synced project and file storage paths are hashed too. Account and session metadata remain managed; direct MCP writes are not encrypted by this CLI setting.

Before anything is uploaded, a redactor scrubs common secret shapes such as cloud keys, API tokens, JWTs and private keys. A built-in deny list skips `.env` files, SSH and cloud credentials, and key files, and you can add your own rules in `.adriveignore`. Redaction is best-effort, though. It is not a security boundary. Use Private Workspace when synced content must not leave your machine in readable form. If it must not be uploaded at all, turn transcript sync off with `adrive privacy --capture-transcripts off` before you start that session.

## Pricing

- **Free, $0:** the whole loop on one machine. Unlimited local resumes with no account, plus 1 GB storage (soft limit), 1 workspace, 3 agents, and 10 cloud resumes a month.
- **Pro, $20/month:** one developer running several agents every day. 50 GB storage (soft limit), 25 agents, and unlimited cross-agent resumes.
- **Team, $30 per seat per month, 3-seat minimum:** 3 to 100 seats, 250 GB storage (soft limit), unlimited cross-agent resumes, workspace roles and invites, and bring your own bucket on R2 or S3.
- **Enterprise:** custom limits, a security review and a DPA.

Every plan keeps all of your session history. Workspace, seat and agent limits are enforced. Storage is a soft limit: warnings start at 80%, and new files and sessions keep syncing past it. Local resumes on one machine are unlimited and need no account; Free includes 10 cloud resumes a month. Check usage with `adrive plan` and upgrade with `adrive upgrade`.

Every plan includes session sync and resume across all five agents, Private Workspace, and $0 egress. Encrypted content cannot be searched by meaning on the server, and resume decrypts locally with your key. Details are on the [pricing page](/pricing).
