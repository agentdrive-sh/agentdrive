**Update, November 13, 2026:** Conductor is staying. An earlier version of this post said Conductor Cloud would shut down and delete user data after November 20. Conductor has since [said it isn't shutting down](https://www.conductor.build/changelog/0.94.2-conductor-is-back), and its [announcement](https://www.conductor.build/announcement) now strikes through the Cloud shutdown. There is no deadline and nothing you need to move. This post now covers the part that still matters: making the sessions you run in Conductor resumable in other agents.

Conductor runs Claude Code and Codex in parallel workspaces. Each session holds the plan, the dead ends and the reasons a change was made, but only the agent that ran it can read that history. AgentDrive syncs those sessions so any coding agent can pick one up: start a task with Claude Code in a Conductor workspace, then continue it in Codex, Cursor, OpenCode or Antigravity, inside Conductor or outside it.

## 1. Install AgentDrive

```bash
curl -fsSL agentdrive.sh/install | sh
```

This installs the `adrive` CLI, signs you in, and wires session sync into Claude Code, Codex, Cursor, OpenCode and Antigravity on this machine. From then on, new sessions sync in the background.

## 2. Sync your existing history

Conductor's workspaces run Claude Code and Codex, which [keep their files in `~/.claude` and `~/.codex`](https://www.conductor.build/docs/faq). To upload the sessions you already have, run:

```bash
adrive sync --all
```

It reads sessions oldest first, up to 50 per run. Run it again until it reports `Synced 0`. Add `--dry-run` to preview the next batch without uploading it. Every plan, Free included, keeps your whole session history.

Sessions are filed by git remote, so work from a Conductor workspace lands in the same project as the rest of that repo. Sync before you delete a workspace folder: a session whose folder is already gone still uploads, but it goes to a separate project named after the folder.

Transcripts are redacted for common secret shapes before upload. Turn on Private Workspace with `adrive privacy --private-workspace on` if you want them encrypted on your machine first.

## 3. Resume in any agent

Open any wired agent in the repo and ask it to resume your last AgentDrive session. In Claude Code, run `/agentdrive:resume`. From a shell:

```bash
adrive resume --list
adrive resume <id from the list>
```

The handoff brief carries the goal, the files touched and the most recent turns. It works in any direction: a Codex session resumes in Claude Code just as well as the other way around.

## What AgentDrive is not

AgentDrive does not run agents in parallel or manage worktrees the way Conductor does. It keeps your sessions and hands work between agents and people. Keep using Conductor to run agents side by side, and use AgentDrive to carry a session from one agent to the next.
